# Upstream Provenance: HBAI-Ltd/Toonflow-app

This directory integrates the Web frontend and browser-side packages from [HBAI-Ltd/Toonflow-app](https://github.com/HBAI-Ltd/Toonflow-app) under the MIT License (`./LICENSE`), adapted as the white-labeled **Creative Plaza (创意广场)** workspace inside Sub2API.

- **Upstream repository**: `https://github.com/HBAI-Ltd/Toonflow-app`
- **Pinned commit**: `2112d7cd65374d11ce67f64790705618c261f597` (`master`)
- **Included upstream modules**:
  - `apps/web` — Creative Plaza Studio Web SPA (Home, Projects, Assets, Plugin Market, 3D TrumanMap pre-visualization, Vue Flow infinite canvas workspace, Dockview document workspace, AI Assistant, MCP/A2A settings)
  - `packages/nodes/*` — all 9 official nodes (`textNode`, `imageNode`, `imageGenerationNode`, `videoNode`, `videoGenerationNode`, `audioNode`, `audioGenerationNode`, `frameAnalysisNode`, `trumanMap`), each with its full upstream `i18n/*.json` across all 22 interface languages
  - `packages/ext/*` — all 5 official document extensions (`canvasNode`, `image`, `md`, `media`, `txt`)
  - `packages/i18n` — all **22 interface languages** (`zh-CN`, `zh-TW`, `en`, `ja`, `ru`, `vi`, `th`, `ko`, `hi`, `id`, `ms`, `fil`, `bn`, `ur`, `ta`, `te`, `mr`, `pa`, `ar`, `fa`, `tr`, `pt`) and Element Plus locale packs, plus runtime brand sanitization (`./custom/i18nOverrides.ts`) and per-package scoped plugin i18n merging (`./runtime/pluginI18n.ts`)
  - `packages/tools/*` — all 12 upstream tool packages (`askUser`, `assetOperator`, `browser`, `canvas`, `ffmpeg`, `pluginDeveloper`, `sandbox`, `skillOperator`, `trumanMap`, `webFetch`, `webSearch`, `workspace`), with browser-capable tools executed directly in `./runtime/agentRuntime.ts` and native/server-only tools honestly marked disabled with `loadError` in Plugin Market
  - `packages/{nodeShared,nodeScaffold,extScaffold,toolScaffold,pluginServer,providerWeb,providers,modelIcons,assets,asr,skills,teams,multiTenant}` and pure TypeScript shared types/constants exported by `@toonflow/server/*`
- **Excluded server/native modules**: `apps/server` runtime (Bun HTTP server), `apps/desktop` (Electrobun), `apps/mobile`, `apps/updateServer`, `compat/ohos`, native FFmpeg binaries, and repository-level docs/screenshots.
- **Sub2API product adaptations (`./custom/`, `./runtime/`, and tailored `upstream/` views)**:
  - **White-label de-branding**: Removed upstream Toonflow logos/watermarks, promotional banners, third-party account/balance/recharge UI, and external Toonflow community/GitHub links; brand identity follows the host Sub2API site logo & localized Creative Plaza name (`./custom/useStudioBrand.ts`, `./custom/i18nOverrides.ts`).
  - **Site-only API enforcement**: Blocked external `toonflow.net`/`toonflow.ai` requests and removed third-party model provider configuration; all text, image, video, and audio model calls route exclusively through the host Sub2API `/v1/*` gateway using the signed-in user's site API keys.
  - **Unified Studio fusion**: Fused Quick Image (`./custom/quickImage/`) into the Studio sidebar navigation (`快捷生图`, also opened automatically via `/image-studio` and `/imagegen` aliases) and unified API key & model binding (`./custom/apiKeysPanel.vue`) into the Studio Settings dialog (`密钥与模型`).
- **Browser-local execution**: All Studio `/api/*` requests are served inside the user's browser by `./runtime/` (IndexedDB virtual workspace & asset storage, site-only AI gateway bridge to Sub2API `/v1/*`, browser AI Assistant with full `/api/agent` streaming & 32 official function tools, TrumanMap Holodeck SingleAgent runtime, browser Streamable HTTP/SSE MCP & A2A clients, browser Plugin Market, and browser HTML5/WebAudio media tools) — consuming zero server compute or server disk.
- **Typecheck & Lint coverage**: `frontend/toonflow/tsconfig.runtime.json` checks all files under `frontend/toonflow/runtime/` and `frontend/toonflow/custom/` via `vue-tsc -p toonflow/tsconfig.runtime.json --noEmit` (wired into `pnpm run typecheck`, `pnpm run build:toonflow`, and `pnpm run build`), and `pnpm run lint:check` lints `frontend/toonflow/runtime/`, `frontend/toonflow/custom/`, and `frontend/toonflow/vite.config.ts`.
