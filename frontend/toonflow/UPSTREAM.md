This directory integrates the real Web frontend and browser-side packages from [HBAI-Ltd/Toonflow-app](https://github.com/HBAI-Ltd/Toonflow-app) under the MIT License (`./LICENSE`).

- **Upstream repository**: `https://github.com/HBAI-Ltd/Toonflow-app`
- **Pinned commit**: `2112d7cd65374d11ce67f64790705618c261f597` (`master`)
- **Included upstream modules** (2,288 files total; 2,286 byte-for-byte identical to pinned commit):
  - `apps/web` — complete Toonflow Web SPA (Home, Projects, Explore, 3D TrumanMap pre-visualization, Vue Flow infinite canvas workspace, Dockview document workspace, AI Assistant, Plugin Market, MCP/A2A settings)
  - `packages/nodes/*` — all 9 official nodes (`textNode`, `imageNode`, `imageGenerationNode`, `videoNode`, `videoGenerationNode`, `audioNode`, `audioGenerationNode`, `frameAnalysisNode`, `trumanMap`), each with its full upstream `i18n/*.json` (all 22 interface languages, byte-for-byte identical to pinned commit)

  - `packages/i18n` — complete upstream i18n package with all **22 interface languages** (`zh-CN`, `zh-TW`, `en`, `ja`, `ru`, `vi`, `th`, `ko`, `hi`, `id`, `ms`, `fil`, `bn`, `ur`, `ta`, `te`, `mr`, `pa`, `ar`, `fa`, `tr`, `pt`) and all 22 Element Plus locale packs (byte-for-byte identical to upstream; Vite strips `with { type: "json" }` in memory during build without modifying upstream files), plus per-package scoped runtime merging via `./runtime/pluginI18n.ts` and `vite.config.ts` covering all 13 plugin/shared i18n directories (`packages/nodeScaffold/i18n`, `packages/nodeShared/i18n`, all 9 `packages/nodes/*/i18n`, `packages/tools/askUser/i18n`, and `packages/tools/canvas/i18n`, 286 files across all 22 locales, lazy-loaded per locale chunk)

  - `packages/{nodeShared,nodeScaffold,extScaffold,toolScaffold,pluginServer,providerWeb,providers,modelIcons,assets,asr,skills,teams,multiTenant}` (including full 22-locale `nodeShared/i18n/*.json` and `nodeScaffold/i18n/*.json`)
